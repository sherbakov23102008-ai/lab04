
Шаг 2. Что видит программа

Программа показывает число логических процессоров, доступных .NET, через 'Environment.ProcessorCount'.

 Логические процессоры по данным программы: 8.
 Физические ядра из Диспетчера задач: 4.
 Логические процессоры из Диспетчера задач: 4.
 Базовая скорость процессора: 2,5 ГГц.

Это значение сравнивают с логическими процессорами, потому что именно их операционная система предоставляет для выполнения потоков.

Шаги 3–5. Эксперимент с потоками

Запустите dotnet run и вводите по очереди 1, 2, 4, 8 и 16. Каждый тест длится около 10 секунд. Во время работы смотрите загрузку CPU в Диспетчере задач.

| Количество потоков | Примерная загрузка CPU  |
| 1                  |           13            |
| 2                  |           25            |
| 4                  |           50            |
| 8                  |           90            |
| 16                 |           95            |

Обычно несколько вычислительных потоков загружают CPU сильнее, чем один. После некоторого количества потоков загрузка может перестать заметно расти: ресурсы процессора уже заняты, а дополнительные потоки требуют переключения.

 Шаг 6. Ядра и логические процессоры

 Физические ядра: 4.
 Логические процессоры: 8.

Количество может отличаться, потому что одно физическое ядро может предоставлять несколько логических процессоров.

Шаг 7. Частота процессора

 Без нагрузки: частота ниже.
 Во время нагрузки: частиота увелич.

Частота может меняться в зависимости от нагрузки, температуры и энергопотребления.

Итоговый вопрос:

Если у компьютера 4 физических ядра и 8 логических процессоров, 'Environment.ProcessorCount == 8' — это нормально. Одно физическое ядро может предоставлять несколько логических процессоров.

Контрольные вопросы:

1. Environment.ProcessorCount показывает число логических процессоров, доступных программе.
2. Физическое ядро — реальная вычислительная часть CPU, а логический процессор — ресурс, который видит операционная система.
3. Несколько потоков могут выполнять вычисления одновременно и загружать больше ресурсов CPU.
4. Загрузка перестаёт расти, когда доступные ресурсы уже заняты; лишние потоки также создают накладные расходы.
5. Частота меняется автоматически в зависимости от нагрузки, температуры и энергопотребления.

Итоговый вывод:

Программа показывает число логических процессоров, доступных .NET. Физические ядра и логические процессоры — не одно и то же. Эксперимент позволяет сравнить загрузку CPU при разном количестве потоков. Обычно несколько потоков повышают загрузку до предела доступных ресурсов. Реальные значения загрузки, частоты и характеристик процессора нужно записать по наблюдениям на своём компьютере.
